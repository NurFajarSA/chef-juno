# Skill

Chef Juno tidak membawa skill bawaan. Cara mereview yang baik sudah dikuasai model; reviewer mode tujuan cukup diberi
tujuan, konteks, dan batas (lihat `docs/guide/03-review-mendalam.md`).

Skill dipakai untuk pengetahuan **khusus tim** yang tidak diketahui model: konvensi modul, pola yang disepakati, hal yang
sering salah di repo kalian. Impor lewat halaman **Skills** (format skill Claude Code: satu folder per skill berisi
`SKILL.md` dengan frontmatter `name`, `description`, opsional `paths` dan `category`).
